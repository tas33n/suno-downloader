# Changelog

## 1.0.0 (unreleased)

- Direct public Suno metadata and guest audio downloads.
- JavaScript ESM/CommonJS exports and TypeScript declarations.
- `getSong`, `getCapabilities`, `downloadSong`, and `saveSong` APIs.
- Original audio by default, with optional installed-FFmpeg MP3/WAV conversion.
- Automatic original-audio fallback and optional strict conversion mode.
- CLI, MIT license, offline tests and cross-platform CI.
